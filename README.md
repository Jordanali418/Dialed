# Dialed

Dialed is a health and fitness tracking web application built with Python, Flask, SQLite, HTML, and CSS. The goal is to create one place for users to manage medications, workouts, daily health habits, and long-term progress.

## Current Features

- Multi-page dashboard
- Medication tracking
- Workout logging
- Persistent data storage with SQLite
- Separate medication and workout pages
- Responsive navigation

## Planned Features

- Reusable workout routines
- Log saved workouts on different dates
- Workout history and progress tracking
- Strength and cardio support
- Daily health tracking
- Sleep and hydration tracking
- Medication completion tracking
- User registration and login
- Secure password hashing
- User-specific data
- Progress charts and statistics
- Input validation
- Accessibility improvements
- Mobile-friendly design

## Run Locally

1. Clone the repository:

```bash
git clone https://github.com/Jordanali418/Dialed.git
```

2. Enter the project folder:

```bash
cd Dialed
```

3. Create a virtual environment:

```bash
python3 -m venv .venv
```

4. Activate the virtual environment on macOS/Linux:

```bash
source .venv/bin/activate
```

5. Install dependencies:

```bash
python3 -m pip install -r requirements.txt
```

6. Start the application:

```bash
python3 app.py
```

7. Open in your browser:

```text
http://127.0.0.1:5000
```
